维格表(Vika) 自动同步 · 设置图文指南

把记账数据自动同步进你的国内云表格，全程无需后端、无需写代码。约 3 分钟搞定。

1 在 vika.cn 新建一个「多维表格」

  1. 打开 https://vika.cn，注册 / 登录。
  2. 点「新建」→ 选「多维表格」（选空白模板即可）。
  3. 进入表格后，看浏览器地址栏，类似：
    https://vika.cn/space/xxxx/yyyy/dstWUHwzTHd2YQaXEE
    其中 dst… 开头那段就是表格ID，整段复制备用。

2 获取 API Token

  1. 点页面左上角头像 → 进入「开发者」（或「开发者中心」）。
  2. 找到 API Token → 点「生成令牌 / 创建」，随便起个名字（如「民宿记账」）。
  3. 生成后复制 usk… 开头的那串令牌，只显示一次，务必存好。
⚠️ Token 写在页面源码里（个人表风险可控）。别有外人拿到这份 HTML 文件即可；不要在公开场合转发。

3 填进记账 App 并同步

  1. 打开记账页 → 展开面板「🟢 维格表自动同步（国内云表格）」。
  2. 表格ID 填 dst…，API Token 填 usk… → 点「保存配置」。
  3. 点「初始化表格」→ 状态应显示「表格结构已就绪（共 11 列）」。
    （若个别列创建失败，面板会提示，你到维格表里手动补建同名列即可。）
  4. 点「上传全部」→ 状态显示「已同步 N 笔到维格表」，去维格表刷新即可看到数据。
  5. 勾上「自动同步」，以后每次生成 / 改动订单，约 0.8 秒后自动覆盖同步到云端。
使用须知：
  1. 云端表格是本地数据的镜像：每次同步用本地当前全部订单完整覆盖云端（不重复累积）。不要在维格表里手动改行，否则下次同步会被覆盖。
  2. 列结构：渠道 / 订单号 / 入住日期 / 退房日期 / 间夜 / 房费 / 清洁费 / 押金 / 实付金额 / 客人 / 电话。
  3. 若「上传全部」报 CORS / 跨域 错误，是浏览器与维格表接口的跨域限制——把报错发我，我给你加一个轻量代理转发即可。
