      🟢 维格表自动同步（国内云表格）
      

        
        
        
        

          
          
          
        

        

        

          
用法（国内可访问、无需后端）：

          
    
            
  1. 打开 vika.cn（维格表）新建「多维表格」，复制浏览器地址里的 表格ID（dst 开头）。
    2. 
            
  2. 左上角头像 → 开发者 → API Token → 生成令牌并复制。
    3. 
            
  3. 填上面两项 → 保存配置 → 初始化表格（自动建好 11 列）→ 上传全部。之后勾自动同步即可每次改动自动覆盖同步。
    4. 
          

          
云端表格仅作本地数据的镜像：每次同步用本地当前全部订单完整覆盖云端，不重复累积。列：渠道/订单号/入住日期/退房日期/间夜/房费/清洁费/押金/实付金额/客人/电话。
