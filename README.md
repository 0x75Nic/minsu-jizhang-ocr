# 天合民宿记账 (minsu-jizhang)

单文件 HTML 民宿记账工具，无需后端、双击即用，支持订单录入、订单截图 OCR 导入、以及维格表（Vika）云端同步。

## 功能
- 订单录入：渠道、入住/退房日期、间夜、房费、清洁费、实付金额
- 维格表云端同步：自动去重 + 按入住日期升序排列
- 订单截图 OCR 导入（美团 / 途家等平台）
- 数据本地存储 + 一键导出

## 文件说明
- `民宿记账1.0.html` — 主程序（单文件，可直接部署或双击打开）
- `维格表设置图文指南.html` — 维格表列结构与同步配置的图文教程
- `htmlcode部署教程.md` — 部署到 htmlcode.fun 的人工教程
- `AI部署教程.md` — 可直接喂给 AI 的部署指令版（复制本文件 + HTML 即可让任意 AI 完成部署）

## 部署
见 `htmlcode部署教程.md`（人工）或 `AI部署教程.md`（交给 AI）。

## 维格表同步
按 `维格表设置图文指南.html` 配置数据表与 API Token 后，在应用内启用同步即可。

> 说明：本仓库为公开示例，不含任何客人订单数据。
